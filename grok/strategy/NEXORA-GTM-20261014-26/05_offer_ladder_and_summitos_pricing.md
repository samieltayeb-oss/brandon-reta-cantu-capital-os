## Offer details
### 1. Connected-Systems Assessment (entry)
- ICP: 3–75-employee firms in trades, property management, home services, light manufacturing (02 top sectors); owner/ops manager buyer.
- Problem: re-keyed data across website, CRM, scheduling, accounting (site framing, 01).
- Verified readiness: Integrations and dashboards advertised LIVE; process "Learn → Plan" published (/transformation). No published integration case study.
- Deliverables: tool inventory, data-flow map, top-5 automation opportunities scored with the free "AI Automation Opportunity Planner", fixed-price proposal for rung 2/3. Exclusions: no build, no licences, no health information.
- Dependencies: client read-only access/screens; no NEXORA tooling needed.
- Effort/risk: low effort (hours UNKNOWN); risk = giving away free consulting; credit fee against next rung (H).
- Pricing model: fixed fee, creditable. Milestones: kickoff → workshop → report. Upgrade: rung 2 or 3.
### 1b. Website + Search Foundation
- ICP: SMBs with dated sites; startups. Problem: site doesn't capture leads into tools.
- Readiness: Websites/brand LIVE; real website clients exist but marked "Needs Delivery Verification" (01). AEO not advertised — add only if delivered.
- Deliverables: site, forms → CRM, schema/search basics. Exclusions: ongoing content, paid ads.
- Risk: commoditized ($499 competitors); sell only as on-ramp to integration, not standalone (H).
- Pricing: fixed build + optional monthly care. Upgrade: rung 2.
### 2. Lead-to-Job Automation Sprint
- ICP: trades, home services, property managers with 2+ sites (e.g., profiles like GROK-20 top-5 — no account is approved for outreach).
- Problem: intake → follow-up → dispatch → invoice handoffs done by hand.
- Readiness: CRM + workflow automation LIVE (advertised); human-in-the-loop approach documented (/ai-automation).
- Deliverables: CRM setup or extension of incumbent (e.g., Rent Manager, Jobber), 2–4 automations with approval rules, failure alerts. Exclusions: platform replacement, licences, custom apps.
- Dependencies: client's SaaS APIs/licences; CASL consent (CRM checklist).
- Effort/risk: medium; API limits of incumbent tools. Pricing: fixed per sprint, scope by workflow count. Milestones: map → build → UAT → go-live. Upgrade: rung 4.
### 3. Connected Operations Build
- ICP: 3–75-employee multi-site firms (wider band only if CEO approves D28) (manufacturing, multi-office trades, distribution) with accounting/ERP + ops tools.
- Problem: no single source of truth; manual reporting.
- Readiness: advertised LIVE but **no public delivery proof** — biggest sales risk. Founder ERP background (/about).
- Deliverables: integration hub, data definitions, dashboards, monitoring. Exclusions: ERP replacement, WMS product (DEMO), health data.
- Dependencies: ERP/accounting API access, possibly middleware licences; client IT.
- Effort/risk: high; scope creep — use paid discovery + milestone billing.
- Pricing: milestone-based fixed quote. Upgrade: rung 4.
### 4. Managed Systems & Automation Care
- ICP: any rung 2/3 client. Problem: automations break when tools change.
- Deliverables: monitoring, fixes, monthly improvement hours, report. Exclusions: new builds beyond hours.
- Support: defined response targets (TBD). Pricing: monthly tiers by number of workflows/systems. Upgrade: new builds.
- Risk: support load unknown → need internal hours data.

## SummitOS pricing evaluation
Baseline (public, 2026-10-14, https://nexorayyc.io/summitos): Foundation CAD $299/mo (up to 10 seats), Live Intelligence CAD $599/mo (up to 25 seats, live supplier feeds, margin risk), Enterprise custom (unlimited seats, ERP/GL integration). Labelled "Proposed pilot subscription", by application.
- Maturity vs value: controlled pilot, one named participant (Blue Moon), draft legal terms. Price points are in the range of published SaaS (Jobber USD plans include $199–$699/mo), so price is not obviously out of market; **the gap is proof, not price** (H).
- Ideal segment: specialty exterior/roofing contractors $5M–$25M (site's own statement) who buy from suppliers whose price lists can be ingested. Only one evidenced discovery candidate in our research (Transformer Exteriors; GROK-20).
- Features/limits: the module list on /summitos exceeds what the narrower product page claims (01) — tier limits should map only to delivered features.
- Cost to serve / onboarding / support: UNKNOWN. "Reviewed onboarding" and "Assisted Price Book & Catalog Configuration" imply material human effort per tenant (H) — likely the real margin driver at $299.
- Competitive position: AccuLynx (roofing) and Buildertrend quote privately; Jobber is self-serve and cheaper at entry. SummitOS wedge = supplier-price impact analysis.
- Adoption friction: switching from incumbent CRM/estimating; data migration; pilot risk perception.
- Margin implications: cannot be computed (no cost data).
- Starter plan? Hypothesis: **not yet** — a $99–149 tier would add self-serve-style support demand to a product with manual onboarding and no public checkout, and would anchor value below Jobber's entry plans.
- Early-adopter incentive vs permanent cut: prefer time-boxed pilot terms (e.g., discount or credits for N months in exchange for feedback/case-study rights) over a permanent cut, which is hard to reverse (general SaaS practice; H).
